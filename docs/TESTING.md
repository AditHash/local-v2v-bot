# Testing and verification

This document tracks **what to test**, not claims that tests have already passed. The initial project has **not** been run end-to-end on the user's Windows device.

## Set up the V1 environment (Windows PowerShell)

```powershell
ollama pull qwen3:0.6b
uv python install 3.12
uv venv --python 3.12
uv pip install -r requirements.txt
.\.venv\Scripts\python.exe -m piper.download_voices en_US-lessac-medium
.\.venv\Scripts\python.exe app.py
```

Visit `http://127.0.0.1:7860`. Gradio should ask for microphone access. The first STT run needs the model download; install all weights before testing offline operation.

## Manual smoke test checklist

- [ ] App launches on Windows 3.12 CPU-only, with no GPU dependency.
- [ ] Record 3–10 seconds of clear English speech; verify STT text is sensible.
- [ ] Response text is generated by local Ollama; synthesized WAV plays.
- [ ] A follow-up question refers to the previous turn.
- [ ] Clear Conversation resets history and transcript/response display.
- [ ] Silent recording produces a helpful error; app stays responsive.
- [ ] Unavailable Ollama service/model gives actionable error.
- [ ] Missing Piper voice gives setup guidance.
- [ ] First-run downloads finish, then internet can be disconnected while inference still works.
- [ ] Check temporary audio files and note that cleanup is pending P1.2.
- [ ] Collect STT / LLM / TTS / total timings for at least three turns.

## Automated tests to add in P1.1

Use `pytest` with adapters/fakes so tests never require model weights, microphone access, or Ollama:
- successful turn and correct roles/history;
- no input audio path;
- empty/whitespace transcript;
- empty LLM response;
- exceptions from each model adapter;
- limited LLM history window;
- session reset;
- timings recorded with an injectable clock when useful.

**Planned, not yet available:**

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Codex should add `pytest` as a documented development dependency before reporting this command as working.

## Review expectations

For each change, report:
- exact tests and commands executed;
- whether real model inference was tested;
- platform/hardware tested;
- observed timings, never guessed performance;
- failures and remediation;
- tasks actually completed in `TASKS.md`.

Never commit recorded personal speech, transcript logs, real microphone samples, downloaded weights, or private configuration to the public GitHub repository.
